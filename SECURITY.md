# Security

Thanks for caring about this.

## Report a vulnerability

Please **do not** open a public issue for security problems.

Email: **hello@alfreddagenais.com** with subject `SECURITY alfred-agent-devkit`.

Include:

- What you found
- Steps to reproduce
- Impact (as you see it)
- Whether you have a suggested fix

I will acknowledge when I can and work a fix without dragging your name into it unless you want credit.

## Scope

In scope: the CLI, package installers/adapters, and published skills/commands/agents in this repo.

Out of scope: vulnerabilities only in third-party tools (Cursor, Claude Code, Node) unless this repo makes them worse.

## Please avoid

- Running destructive PoCs against systems you do not own
- Publishing exploit details before a fix lands
