# Language: English in Code

- **All code** (variable names, comments, log messages, UI strings, error messages) must be written in **English** at all times.
- This applies unless the user explicitly requests otherwise for a specific context.
- Keep other languages only for user-facing documentation that targets that audience, when explicitly requested.
