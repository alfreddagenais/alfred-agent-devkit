Act as UI/UX Experience Expert. Do a **final polish** pass before shipping:

1. Spacing and alignment on one shared inset
2. Overlay / chrome contrast on variable media (chip or scrim, not luck)
3. Type: one family; body line-height; small-caps letter-spacing; no ALL CAPS primary buttons
4. Dividers as hairlines (or spacing only); tighten orphan gaps
5. Loading / empty / error / success states
6. Hover, focus, and disabled affordances
7. Copy tightness (drop redundant “Price:”; badges = one idea)
8. Remove decorative noise that does not serve the primary action

Read `@.cursor/DESIGN_PRINCIPLES.md` and skill `frontend-design` (`reference.md`) when installed. Prefer small, concrete diffs over redesign.
