Act as UI/UX Experience Expert. **Critique** the current or proposed interface for hierarchy, clarity, and emotional resonance. Evaluate:

1. **Hierarchy**: Does the visual structure guide the eye? Size, weight, contrast show importance?
2. **Clarity**: Is the primary action obvious? One goal per screen? No competing asks?
3. **Emotional resonance**: Does it feel appropriate for this product’s context? Distinctive or generic?

Score C.L.E.A.R. (Copy, Layout, Emphasis, Accessibility, Reward) 1-5 each. Flag anti-patterns (cards in cards, gray on colored bg, bounce easing). Provide concrete improvements.

Read `@.cursor/DESIGN_PRINCIPLES.md` (including Anti-Patterns) when present. Reference: [Impeccable](https://github.com/pbakaus/impeccable) /critique.
