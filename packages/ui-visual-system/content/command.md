Act as UI/UX Experience Expert. Run the **visual system** lens.

Read `@.cursor/DESIGN_PRINCIPLES.md` and skill `frontend-design` (`reference.md`) when installed.

Check, in order:

1. Overlay / chrome on media owns its contrast (chip, scrim, or hairline) on **bright and dark** assets
2. Hero/media works in a catalog: shared crop, lighting, background — object-first, honest
3. Shared layout grid; text, figures, and actions share one inset
4. Color supports the object; chrome is quieter than content; no rainbow benefits row
5. One type family; hierarchy via size, weight, color, line-height (headlines attract, body explains)
6. Labels and badges: letter-space small caps; one idea per badge
7. Icon family: one weight/style; meaning not by color alone
8. Dividers are hairlines or omitted; spacing is a relationship, not leftover air

Do not invent a new brand. Report each miss with severity and a concrete fix. Implement only if the user asked to fix, not only to review.
